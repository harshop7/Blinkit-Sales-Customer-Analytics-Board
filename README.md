# Blinkit Sales & Customer Analytics Dashboard

## Project Overview
This project focuses on analyzing Blinkit grocery sales data using Power BI, MySQL, and Python. The main objective was to perform data cleaning, KPI analysis, and generate business insights through interactive visualizations and SQL analysis.

The dashboard helps in understanding:
- Sales performance
- Outlet analysis
- Customer ratings
- Product category trends
- Outlet size and location performance

## Business Insights
- Tier 3 outlets generated the highest sales contribution.
- Snack Foods and Fruits & Vegetables were among the top-performing item categories.
- Medium-sized outlets showed better overall sales performance.
